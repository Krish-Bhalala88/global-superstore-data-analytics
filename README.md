# 🌍 Global Superstore — End-to-End Data Analytics Case Study

> **SQL → Python → Excel → Power BI → Business Insights**

An end-to-end **Data Analytics & Business Intelligence portfolio project** built using the Global Superstore dataset.

This project demonstrates the complete data analytics lifecycle — from raw data exploration and SQL analysis to Python EDA, Excel reporting, Power BI dashboards, DAX calculations, and actionable business recommendations.

---

## 📌 Project Overview

The Global Superstore dataset contains transactional information related to:

- Sales
- Profit
- Customers
- Products
- Categories
- Sub-Categories
- Markets
- Regions
- Countries
- States
- Segments
- Discounts
- Shipping
- Orders

The purpose of this project is to transform raw transactional data into meaningful business insights that can support better decision-making.

---

# 🎯 Business Objectives

The project focuses on answering important business questions:

- 📈 How are sales performing over time?
- 💰 Which categories and sub-categories generate the most profit?
- 👥 Which customer segments are most valuable?
- 🏆 Who are the top customers?
- 📦 Which products generate the highest sales?
- ⚠️ Which products and sub-categories are loss-making?
- 🌍 Which markets and regions perform best?
- 🚚 Which shipping modes are most frequently used?
- 💸 How does discounting affect profitability?
- 📊 Which areas require management attention?
